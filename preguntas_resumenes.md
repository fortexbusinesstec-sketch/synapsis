## Pregunta 8: Procedimiento para registrar LOPs (Botoneras) en el 3300.

**ID:** Q042

| Opción | Resumen (máx. 20 palabras) |
|--------|---------------------------|
| A (B5) – Pipeline completo | Cambia a LE00, pulsa OK y busca indicador LC parpadeando en la HMI. |
| B (E) – Sin router/verificador | Ingresa a modo configuración, verifica LE00 y revisa circuito de seguridad. |
| C (D) – Solo RAG + LLM base | Escucha sonido de confirmación DT-O en la COP al pulsar el botón. |

## Pregunta 11: Valor nominal de resistencia para bobinas de freno MGB.

**ID:** Q062

| Opción | Resumen (máx. 20 palabras) |
|--------|---------------------------|
| A (B5) – Pipeline completo | Mide resistencia MGB: 190-1700 Ω (FML/PML) o 80-120 Ω (FMR/PMR). |
| B (E) – Sin router/verificador | Mide resistencia MGB con rangos específicos según el tipo de máquina. |
| C (D) – Solo RAG + LLM base | Admite no tener datos de MGB y sugiere revisar el manual del fabricante. |

## Pregunta 12: ¿Dónde se ubica físicamente la HMI en el sistema Bionic 5 (3300 sin cuarto)?

**ID:** Q081

| Opción | Resumen (máx. 20 palabras) |
|--------|---------------------------|
| A (B5) – Pipeline completo | La HMI está integrada en la LDU del ascensor. |
| B (E) – Sin router/verificador | La HMI está en la LDU, parte frontal con LEDs y pulsadores. |
| C (D) – Solo RAG + LLM base | No responde ubicación; sugiere escuchar sonidos inusuales al encender. |

## Pregunta 13: Identificación visual de pines para contacto KB cerrado (Freno PML 200).

| Opción | Resumen (máx. 20 palabras) |

| B (E) – Sin router/verificador | Mide resistencia en cable KB entre pines 1-2; debe ser aprox. 0 Ω. |
| C (D) – Solo RAG + LLM base | Verifica LEDs del freno: KB debe estar ON y KB1/KB3 apagados. |
