# 📚 Material de Investigación — Synapsis MAS

Esta carpeta contiene todo el material académico, documentación de investigación y artefactos de evaluación **no esenciales para la ejecución del código** de producción.

## 📂 Contenido

| Directorio | Descripción |
|:---|:---|
| `docs/` | Documentación técnica y metodológica: guías de ablación, análisis de contexto conversacional, arquitectura ArchiMate, EDT del proyecto, casos de prueba. |
| `imagenes/` | Diagramas de arquitectura, figuras para publicaciones, diagramas de base de datos, pipelines de evaluación. |
| `scripts/diagrams/` | Scripts Python (Graphviz) para generar diagramas HD automáticamente. |
| `scripts/evaluation/` | Scripts de experimentos: ablación, evaluación L0/L1/L2, seeds de datos de prueba. |
| `scripts/tmp/` | Scripts temporales y de prueba descartables. |

## 🚀 Código de producción

El código funcional de la aplicación está en la raíz del proyecto:
- `app/` — Frontend y API routes
- `components/` — Componentes React
- `lib/` — Agentes, base de datos, utilidades
- `scripts/database/` — Scripts de mantenimiento operativo
- `scripts/utils/` — Utilidades de operación
